# ✅ Definition of Done

Um jogo só deve ser considerado pronto quando:

- [ ] Não existem bugs críticos
- [ ] Todos os cenários foram revisados
- [ ] Todos os sistemas funcionam
- [ ] Save/Load funciona
- [ ] Áudio completo
- [ ] UI completa
- [ ] Tutorial funcional
- [ ] Créditos adicionados
- [ ] Configurações prontas
- [ ] Localização revisada
- [ ] Performance aceitável
- [ ] Build final gerada
- [ ] Backup realizado
- [ ] Trailer pronto
- [ ] Página da loja publicada
- [ ] QA aprovado

---

# 💡 Dica

Durante o desenvolvimento, mantenha três listas sempre atualizadas:

## TODO

Tudo que ainda precisa ser feito.

## DOING

O que está sendo desenvolvido atualmente.

## DONE

Tudo que foi concluído e validado.

> "Um jogo excelente não nasce pronto; ele evolui através de centenas de pequenas decisões bem executadas."
